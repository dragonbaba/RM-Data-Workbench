## 1. 需求

### 背景
上一轮把 `isRare` 错挂到了 `Items.json` 的物品本体上，但用户真实需求是把它加到敌人掉落项 `enemyDrops[]` 上，用来描述“这个敌人的这个掉落是否属于稀有掉落”。因此需要撤回前一轮对物品属性面板和物品类型的改动，把字段迁移到敌人掉落单项。

### 目标
- 将 `isRare` 从物品本体迁移到 `enemyDrops[]` 单项。
- 掉落编辑行调整为四列：`掉落类型 -> 掉落概率 -> 是否稀有 -> 掉落目标`。
- 前三列保持窄宽度，最后一列“掉落目标”继续占主要宽度。
- 保持现有掉落模式保存链路和引用联动不变。

### 约束条件
```yaml
时间约束: 本轮直接修正上一轮误实现，不再保留双轨兼容
性能约束: 不新增额外数据文件和查询链路
兼容性约束: 旧 enemyDrops 缺失 isRare 时按 false 处理
业务约束: 字段名固定为 isRare，且只属于 enemyDrops 单项
```

### 验收标准
- [ ] `EnemyDropEntry` 新增 `isRare?: boolean`
- [ ] `DropPanel` 单行变为四列，顺序为类型/掉率/是否稀有/掉落目标
- [ ] `PropertyPanel`、`RPGItem` 与相关测试中移除错误的物品级 `isRare`
- [ ] 组件测试覆盖掉落项 `isRare` 的显示与保存行为

## 2. 方案

### 技术方案
前端类型层将 `isRare` 从 `RPGItem` 移除，改为加入 `EnemyDropEntry`。`DropPanel` 使用 `Switch` 编辑该字段，并在归一化函数中把缺失值视为 `false`。布局从三列改为四列，采用“前三列窄、最后一列宽”的比例网格。上一轮新增的 `PropertyPanel` 物品级 `isRare` 逻辑和测试全部撤回，改为新增 `DropPanel` 组件测试。

### 影响范围
```yaml
涉及模块:
  - frontend/src/types/index.ts: enemyDrops 结构修正
  - frontend/src/components/panels/DropPanel.tsx: isRare UI 与四列布局
  - frontend/src/components/panels/PropertyPanel.tsx: 撤回误加的物品级 isRare
  - frontend/src/components/panels/*.test.tsx: 从属性面板测试迁移到掉落面板测试
  - .helloagents/modules/*: 同步掉落规则和属性面板文档
预计变更文件: 8
```

## 3. 技术设计

### 数据模型
| 字段 | 类型 | 说明 |
|------|------|------|
| dropType | `0 | 1 | 2` | 掉落类型，映射物品/武器/防具 |
| dropChance | `number` | 掉落概率，范围 `0-100`，允许小数 |
| isRare | `boolean` | 当前掉落项是否属于稀有掉落，缺失时按 `false` |
| dropId | `number` | 引用的物品/武器/防具 ID |

## 4. 核心场景

### 场景: 标记敌人的某个掉落为稀有掉落
**模块**: DropPanel
**条件**: 当前文件为 `Enemies.json`，当前敌人存在至少一个掉落项
**行为**: 用户在掉落行中切换“是否稀有”开关并保存
**结果**: 当前敌人的对应 `enemyDrops[index].isRare` 被写回并标脏

### 场景: 打开旧掉落数据
**模块**: DropPanel
**条件**: `enemyDrops[]` 项缺失 `isRare`
**行为**: 编辑器读取并渲染掉落列表
**结果**: 该项在 UI 中按“否”展示，不报错

## 5. 技术决策

### drop-entry-is-rare-flag#D001: 稀有标记只属于 enemyDrops 单项
**日期**: 2026-03-24
**状态**: ✅采纳
**背景**: 用户明确纠正：稀有标记表示“某个怪的某个掉落是否稀有”，而不是“这个物品天生稀有”。
**选项分析**:
| 选项 | 优点 | 缺点 |
|------|------|------|
| A: 挂在 `enemyDrops[].isRare` | 精确表达单怪单掉落语义，不污染全局物品库 | 同一物品在不同怪物上可出现不同稀有标记 |
| B: 挂在 `Items.json.isRare` | 结构简单，所有引用都能读到 | 语义错误，无法表达“只对某个敌人的某个掉落稀有” |
**决策**: 选择方案 A
**理由**: 该字段描述的是掉落上下文属性，不是物品静态属性，应跟随掉落条目持久化。
**影响**: 影响掉落数据结构、掉落面板 UI、测试和知识库说明
